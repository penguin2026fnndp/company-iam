# company-iam
# 统一权限管理系统（IAM）

面向全公司 1 万+ 员工、20+ 业务系统的集中式身份与权限管理平台。

一个公司账号通行全部业务系统，以岗位驱动的 RBAC 模型集中管理功能级权限，申请审批嵌入 OA 流程，系统自身按三权分立治理。

> 当前阶段：需求分析 · 文档 v0.3（骨架版）· 2026-10-15
> 说明：本仓库为课程作业项目，文中公司与系统均为虚拟示例

## 建设目标

| 目标 | 含义 |
|------|------|
| 一个账号 | 员工凭一个公司账号登录全部已接入系统 |
| 一处授权 | 权限统一在 IAM 中按「岗位—角色—功能点」授予 |
| 一条流程 | 权限申请与审批走 OA，通过后自动生效 |
| 一本明白账 | 所有授权、变更、登录行为可查可追溯 |

## 核心设计

- 岗位驱动的 RBAC：权限沿「人 → 角色 → 功能点」传递
- 基线 + 差量：分公司差异以「增量 / 禁用」表达
- 三权分立：系统管理员、安全管理员、审计员互斥，不设超级管理员
- 实时判定：权限变更即时生效，会话可强制踢出
- 内外网双入口：共用同一套账号与权限，外网强制多因素认证
