### 2.3 三权分立

| 角色 | 应有权限 | 不应有 |
| --- | --- | --- |
| SYS_ADMIN | USER:*、PERM:*、DEPT:*，共 13 项 | 任何 OA/IM/KM 业务权限、任何 ROLE:* |
| SEC_ADMIN | ROLE:*、APPLY:APPROVE，共 7 项 | 用户管理、部门管理、权限目录写权限、任何业务权限 |
| AUDITOR | 所有 VIEW | 任何 ADD/EDIT/DELETE/EXPORT/APPROVE |
| LEADER | 按公司领导列分配的 52 项业务权限 | Excel 未授权的新增、编辑等动作 |
| MGR | 按部门经理列分配的 67 项业务权限 | Excel 标记“无”的功能动作 |
| PM | 按项目经理列分配的 51 项业务权限 | Excel 未授权的审批等动作 |
| EMP | 按普通员工列分配的 43 项业务权限 | Excel 标记“无”的功能动作 |
| SUPER_ADMIN | 全部 274 项权限 | 无 |

| 用例 | 操作 | 预期 |
| --- | --- | --- |
| RBAC-01 角色模板 | 查询角色列表 | 8 个角色：SYS_ADMIN、SEC_ADMIN、AUDITOR、LEADER、MGR、PM、EMP、SUPER_ADMIN |
| RBAC-02 权限目录 | 查询全部权限 | 274 枚 |
| RBAC-03 OA 权限 | `sysCode=OA` | 18 功能点 × 6 操作 = 108 |
| RBAC-04 IM 权限 | `sysCode=IM` | 12 功能点 × 6 操作 = 72 |
| RBAC-05 KM 权限 | `sysCode=KM` | 12 功能点 × 6 操作 = 72 |
| RBAC-06 六类动作 | 查询“收文登记与流转” | VIEW、ADD、EDIT、DELETE、EXPORT、APPROVE 齐全 |
| RBAC-07 审计只读 | 查询 AUDITOR 角色权限 | 48 项全部是 VIEW |
| RBAC-08 公司领导矩阵 | 查询 LEADER 角色权限 | 53 项；含“发文拟稿与审核”的查看/审批，无编辑 |
| RBAC-09 部门经理矩阵 | 查询 MGR 角色权限 | 73 项；含“发文拟稿与审核”的查看/编辑/审批 |
